## After: CI

Each job that uses uv reads the version out of the Dockerfile and gives it to the pinned action.

```bash
cd /home/frankbria/projects/worktrees/issue-819-pin-uv && sed -n '/- name: Read the pinned uv version/,/prune-cache: true/p' .github/workflows/tests.yml | head -14
```

```output
      - name: Read the pinned uv version
        id: uv
        run: |
          version=$(sed -n 's|^FROM astral/uv:\([0-9][0-9.]*\)@sha256:.*|\1|p' backend/Dockerfile)
          [ -n "$version" ] || { echo "::error::backend/Dockerfile pins no uv version"; exit 1; }
          echo "version=$version" >> "$GITHUB_OUTPUT"

      - name: Setup uv
        uses: astral-sh/setup-uv@c18668ad3cf93ea998bef934396af7bb5c839dc7 # v10.2.0
        with:
          version: ${{ steps.uv.outputs.version }}
          enable-cache: true
          cache-dependency-glob: backend/uv.lock
          prune-cache: true
```
